# Evaluation Metrics

## 1. Accuracy

Exact match or LLM-based grading.

---

## 2. Cost

- API cost estimation

---

## 3. Latency

Measured in seconds per task.

---

## 4. Efficiency Score

Efficiency = Accuracy / Cost

---

## 5. Stability

Variance across repeated runs.

---

## 6. Adaptation Performance

- Early phase vs late phase performance
